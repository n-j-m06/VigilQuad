## 🚀 Project Overview

VigilQuad is an advanced AI-powered proctoring solution specifically designed for **NEET and large-scale online examinations**. The platform leverages computer vision, real-time monitoring, and intelligent behavioral analysis to maintain examination fairness and detect suspicious activities during remote assessments.

A unique aspect of VigilQuad is its **Quadrant Monitoring System**, which divides a candidate's monitoring space into four distinct zones, enabling more precise tracking of movement, gaze direction, and environmental anomalies. This approach enhances invigilation accuracy while reducing false alerts.

## 🔲 The VigilQuad Quadrant System

The name **VigilQuad** originates from its innovative **Quadrant Surveillance Framework**.

During an examination, the monitoring area is divided into four intelligent quadrants:

| Quadrant | Monitoring Focus |
|-----------|------------------|
| Q1 | Upper-Left Region |
| Q2 | Upper-Right Region |
| Q3 | Lower-Left Region |
| Q4 | Lower-Right Region |

This quadrant-based approach allows the system to:

- Track candidate movement patterns
- Detect prolonged off-screen behavior
- Identify unusual head and gaze shifts
- Improve anomaly detection accuracy
- Generate contextual alerts based on movement direction

By analyzing activity across all four quadrants, VigilQuad provides a more comprehensive understanding of candidate behavior compared to conventional monitoring systems.
